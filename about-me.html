Hii, I'm Nicole! I first started working on this project back in 2024 when most of it was in my brain and a few scattered notebooks. I've been working on it ever since and it's grown a tad out of control. I even started running a ttrpg campaign in 2026 in my world. It's helped me learn so much about astronomy, linguistics, biology, art, and so much more — its been super fun!

How this site was made

Everything about the world of Ae’Uuvoria is mine: the lore, story, characters, languages, magic system, maps and art. I built the site with help from Claude, an AI, which wrote and edited much of the code. Much of the placeholder text was also added by Claude using my extensive notes in obsidian, I plan to go back through and rewrite all the placeholder text myself. No AI was used for any art. I’m learning web design as I go, so this has been a project in understanding how all of it works. I tried building this page in particular from scratch by myself and now I have an insane amount of appreciation for actual developers <3

Programs used

  • Dreamweaver — used to program the website
  • Illustrator — used to make the planetary chart, planet icons, and other various symbols
  • Procreate — used to draw the maps and more detailed illustrations
  • Obsidian — used to outline everything and basically where all my word vomit and half-baked ideas live
  • Google Docs — same as obsidian I'm just inconsistent
